# Note 1: Understanding the ZFC Axioms

The Zermelo-Fraenkel set theory (ZFC) is a foundational system of axiomatic set theory in mathematics. It is widely used in the formalization of mathematics.

## Axioms of ZFC

1. **Extensionality**: Two sets are equal if and only if they have the same elements.
2. **Empty Set**: There exists a set with no elements, called the empty set.
3. **Pairing**: For any two sets, there exists a set that contains both of them as elements.
4. **Union**: For any collection of sets, there exists a set that contains all the elements of the sets in the collection.
5. **Power Set**: For any set, there exists a set that contains all the subsets of the original set.
6. **Infinity**: There exists an infinite set.
7. **Comprehension (Separation)**: For any set and any property, there exists a subset of the original set that contains all the elements with the given property.
8. **Replacement**: For any set and any function, the image of the set under the function is also a set.

## Conclusion

Understanding the ZFC axioms is crucial for working with set theory and formalizing mathematics.
